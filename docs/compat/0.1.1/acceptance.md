## 3. エラーの表示 (NFR-604)

| 場合 | 結果 | 確かめた日・版 |
|---|---|---|
| llama-server に繋がらない: 「会話のデータには触れていないので、無事です」が出る | 合 | 2026-11-10、0.1.1 (判定コミット ac54d672、`cargo xtask dist` で作り本物の鍵で署名した配布物)、利用者が確認 |
| データ根を使えない (2 つ同時に起動): 日本語の理由 (pid つき)、データは無事、先に起動した evorag を終える案内 | 合 | 同上 |
| API キーの誤り (HTTP 401): API キーが受け付けられなかったこと、環境変数の名前、データは無事。「起動してから」は出ない | 合 | 同上 |

v0.1.0 の所見 1〜3 ([`docs/compat/0.1.0/release-checklist.md`](../0.1.0/release-checklist.md)) が直ったことを確かめた。設定の誤り・DB の破損の表示は変わっていない (v0.1.0 の結果のまま)。

## 4. 配布物の検証 (12 §5)

| 確かめること | 結果 | 確かめた日・版 |
|---|---|---|
| `SHA256SUMS` と minisign の署名を、同梱の手順書どおりに確かめられる | 合 | 2026-11-10、0.1.1 (判定コミット ac54d672、`cargo xtask dist` で作り本物の鍵で署名した配布物)、利用者が確認 |

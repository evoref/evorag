## 1. 忘れると古い版 (09 §3.6、AC-FR-307-6)

自動の試験 (`forget_wiring.rs::forgets_survive_a_round_trip_through_v0_2`) は、v0.2.x をストアの設定で模している。実際の v0.2.x の実行ファイルで、次を確かめる。

- [ ] v0.3 で忘れた後のデータ根を v0.2.x で開いて閉じると、`meta` の `compact.pending` と、`forget_backups` の job が残っている (v0.2.x が当てずに残す)。
- [ ] v0.2.x で開いている間、伏せ字にしたターンが伏せ字のまま表示される (伏せ字の前に戻らない)。
- [ ] v0.2.x で、伏せ字にしたターンのあるセッションに会話を足し、月をまたいだ日付の環境で閉じる (後の月のジャーナルのファイルに行が足される)。v0.3 で開き直すと、そのファイルも書き直され、データ根のどのファイルにも忘れた値が残らない (ID の時刻でファイルを選ばない)。
- [ ] v0.3 で開き直した後、`evorag repair` を実行しても、伏せ字の前の本文に戻らない。
- [ ] v0.3 で開き直した後、退避 (`backups/`) のどの DB にも忘れた値が残らない。

## 2. 本体の更新の実際の取得 (09 §3.7、12 §7.5)

自動の試験は偽の Releases で行う。実際の GitHub で次を確かめる (v0.3.0 のリリースの後に、次の版の候補で行う)。

- [ ] `evorag update check` が、新しい版と変更の要点を示す。
- [ ] `evorag update apply` が置き換え、新しい版の `--version` が合う。
- [ ] `evorag update rollback` で前の版に戻る。

## 1. 端末と日本語入力 (07 §2.3、AC-NFR-402-1)

v0.2 の合格条件の組み合わせ: GNOME Terminal + fcitx5、GNOME Terminal + ibus (Linux x86_64)。tmux の中でも同じことを確かめる。v0.1 の組み合わせ (Windows Terminal + Microsoft IME (新・旧)、Google 日本語入力、ATOK) も、判定コミットの作りで確かめ直す。

| 組み合わせ | 確かめること | 結果 | 確かめた日・版 |
|---|---|---|---|
| GNOME Terminal + fcitx5 | 変換の候補の窓と変換中の文字が入力位置に出る。確定した文字が欠けず重ならない。全角・半角の混じった行と、折り返した 2 行目でも位置が合う | 未 | |
| GNOME Terminal + ibus | 同上 | 未 | |
| GNOME Terminal + tmux + fcitx5 (または ibus) | 同上。tmux の窓を分けたときと、切り替えて戻ったときも位置が合う | 未 | |
| Windows Terminal + Microsoft IME (新・旧)、Google 日本語入力、ATOK | 同上 (v0.1 の組み合わせを確かめ直す) | 未 | |

## 2. 詳細の窓の操作と日本語入力 (AC-FR-412-3)

1 の各組み合わせで、日本語入力を有効にしたまま次を確かめる。

| 確かめること | 結果 | 確かめた日・版 |
|---|---|---|
| 応答の下の「関係しそうな記録」を Tab で選び、Enter で詳細の窓を開ける | 未 | |
| 詳細の窓で、矢印で「添えて作り直す」「無関係の印」を選び、Enter で実行できる (`a`・`x` を押さなくても操作できる) | 未 | |
| 詳細の窓を Esc で閉じると、入力欄の変換中の文字が失われない | 未 | |

- 帯を出すには、リランカーのある構成で、しきい値の少し下になる問いをする (`/memory` で値を確かめられる)。

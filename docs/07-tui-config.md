## 1. 方針

- 画面はコアの API (02 §3) の命令を出し、イベントを描画するだけにする。
- 公開する名前 (スラッシュコマンド・サブコマンド・設定のキー) は、版の列で入る時期を示す。後の版のものも名前だけは予約し、別の意味で使わない。

## 2. 画面

### 2.1 構成

```
┌ evorag ─ セッション: 旅行の計画 ───────────────────────────┐
│ あなた  10:02                                              │
│   来月の京都の件、前に話した宿はどこだっけ？                │
│ evorag  10:02                                              │
│   以前の会話 [1] では「鴨川沿いの町家」を候補にしていました。│
│                                                            │
├────────────────────────────────────────────────────────────┤
│ > _                                                        │
├────────────────────────────────────────────────────────────┤
│ 127.0.0.1:8080 │ qwen3-32b │ 1,234 / 32,768 │ 待機中       │
└────────────────────────────────────────────────────────────┘
```

- **会話の表示**: ターンを時刻つきで並べる。スクロールできる。中断・失敗のターンと、応答の無いまま残った発話 (強制終了の後など) は印を付ける。
  - 時刻は、v0.1 では UTC で示し、`UTC` と添える。地方時は、C を含む依存なしで OS のタイムゾーンを得る方法を決めてから入れる (ADR-0015)。
- **入力欄**: 複数行。Enter で送信、Shift+Enter (端末が区別できないときは Alt+Enter) で改行。
- **状態の行**: 接続先、モデル、使ったトークン数 / n_ctx、裏の処理の状態 (待機中・整理中・学習中・退避を整理中)。v0.5 から有効なカートリッジの数。
- **Markdown**: 見出し・太字・コードブロックだけを装飾する (FR-109)。
- **出典**: 応答の中の `[n]` を選ぶ (Tab で移動し Enter) と、出典の詳細を表示する (FR-110)。

### 2.2 生成中

- 応答は逐次表示する。Esc で中断する (FR-102)。
- 生成中も入力欄に次の発話を書ける (送信は応答の完了か中断の後)。

### 2.3 日本語入力

- 描画のたびに、端末の本当のカーソルを入力欄の入力位置に置き、隠さない (IME の候補の窓が入力位置に出るようにするため)。
- 文字の幅は `unicode-width`、書記素の区切りは `unicode-segmentation` で数える。

| 版 | 合格条件とする組み合わせ |
|---|---|
| v0.1 | Windows Terminal + Microsoft IME (新・旧)、Google 日本語入力、ATOK |
| v0.2 | GNOME Terminal + fcitx5、ibus (Linux) |
| v0.6 | Terminal.app + 日本語入力 (macOS、実機を確保したとき) |

- conhost (従来のコンソール) は best effort とし、合格条件に入れない。

### 2.4 外部のエディタ

- Ctrl+E で、入力欄の内容を一時ファイルに書いて外部のエディタで開く。閉じたら内容を入力欄に戻す (FR-107)。
- エディタは `VISUAL` → `EDITOR` → (Windows) `notepad.exe` の順に選ぶ。一時ファイルは所有者だけの権限で、状態のフォルダに置き、送った後に消す。

### 2.5 キー

| キー | 操作 |
|---|---|
| Enter | 送信 |
| Shift+Enter / Alt+Enter | 改行 |
| Esc | 生成の中断 / 画面の窓を閉じる |
| Ctrl+E | 外部のエディタで書く |
| PageUp / PageDown | 会話のスクロール |
| Tab | 出典の番号の移動 |
| Ctrl+C | 生成中は中断。入力欄に文字があれば入力欄を空にする。入力欄が空なら、続けて 2 回で終了 |
| Ctrl+Q | 終了 |

## 4. 設定

### 4.1 ファイル

- 置き場所は 03 §2.1。TOML で、先頭に `version = 1` を持つ (版の移行は 03 §12.3)。
- 読めないキー・型の誤り・範囲外の値は、行番号つきのエラーを出して起動しない (FR-904)。後の版で足すキーを古い版が読んだときは、警告を出して無視する (古い版に戻しても起動できるようにするため)。
- 利用者が画面から変えた設定 (セッションごとの出典など) は `config.toml` ではなく DB の `setting` に置く。

| コマンド | 内容 | 版 |
|---|---|---|
| `evorag` | TUI を開く | v0.1 |
| `evorag setup` | llama-server を探し、能力を確かめ、プロンプトの言語を尋ね (新しいデータ根のとき、§6.1)、`config.toml` を書く (FR-510) | v0.1 |
| `evorag doctor [--deep]` | 読むだけで点検する (03 §10) | v0.1 |
| `evorag restore <退避>` | 退避から戻す | v0.1 |
| `evorag export <出力先>` | 書き出す (03 §11) | v0.1 |
| `evorag backups list` | 退避の一覧 | v0.1 (Should) |
| `evorag reset` | データ根を消す (確認あり) | v0.1 (Should) |
| `evorag rebuild [--index]` | 派生データ (または索引だけ) を作り直す。埋め込みのモデルを替えたときも使う | v0.2 |
| `evorag repair` | 副索引と関係を作り直し、ジャーナルから戻す | v0.3 |
| `evorag backups purge` | 退避を消す | v0.3 |
| `evorag update check|apply|rollback` | 本体の更新 (12 §7) | v0.3 |
| `evorag cartridge add|build|list|enable|disable|remove|verify` | カートリッジの操作 (14) | v0.5 |
| `evorag import <書き出し>` | 空のデータ根へ取り込む | v0.6 |
| `evorag eval retrieval` | 検索の評価を流す | v0.6 |

- 共通のオプション: `--data-root <パス>`、`--config <パス>`、`--version`、`--help`。
- 終了コード: 0 正常、1 一般のエラー、2 データ根が使えない (ロック・危ない置き場所・新しい形式)、3 llama-server に繋がらない、4 設定の誤り、5 署名・検証の失敗。

## 6. 文言 (i18n)

- コアは利用者に見せる文言を文言キー (`MessageKey`) と引数で返し、画面がカタログ (`locales/<言語>.toml`) で訳す (FR-907)。
- v0.1 は `ja` だけを同梱する。`en` は v0.3 で同梱する (v0.6 から前倒し、確定 (ユーザー回答)、[OQ-08](10-decisions.md#oq-08-ui-の言語とプロンプトの言語))。
- CI でカタログとコードの文言キーの差分を検査する (NFR-602)。
- ログは英語 (02 §7)。

### 6.1 プロンプトの言語

システムプロンプトと補助の呼び出し (ノート、事実の抽出、訂正の検証、言い換え、precept の提案、採点) のプロンプトの言語は、UI の言語とは別に扱い、**データ根ごとに 1 つに固定する** (確定 (ユーザー回答、2026-11-09)、OQ-08、FR-909)。

| 時点 | 動き |
|---|---|
| 初回の起動時 (新しいデータ根) | 設定 `prompt.language` があればその値にする。無ければ `evorag setup` (または最初の TUI の起動) で選ばせる。既定の選択肢は UI の言語 |
| 決めたとき | `evorag.redb` の `meta` に記録し、ジャーナルにも操作として残す |
| 以後の起動 | 記録した言語で動く。`prompt.language` が記録と違えば、記録した言語のまま動き、変えられない理由を警告する |
| 変えたいとき | 途中では変えられない。新しいデータ根で始める (`--data-root` か `evorag reset`) |

- 応答は、利用者の発話の言語に合わせるようシステムプロンプトで指示する (プロンプトの言語が `ja` でも、英語の発話には英語で答える)。
- 固定する理由: プロンプトを変えると作りの指紋が変わって学習の取り直しが起き (13 §8)、ノートと事実の抽出の結果の言語もそろわなくなる。
- 同梱するプロンプトは `ja` と `en` (v0.1 から両方を用意し、試験は両方で流す)。

# evorag 仕様書 (docs/)

evorag は、手元の llama-server (llama.cpp) だけで動く、Rust 製のチャットと長期メモリのツールである。以前の会話と利用者についての事実を出典つきで応答に添え、利用者の評価と訂正から短い指示 (precept) を学ぶ。モデルの重みは学習しない。TUI 版を最小核 (v0.1) から段階的にリリースし、本体は OSS (Apache-2.0) で公開する。本ディレクトリはその **仕様書群** で、仕様書駆動 ([ADR-0001](10-decisions.md#adr-0001-仕様書駆動での開発)) で開発する。

## 1. 位置づけ

- カートリッジは、文書をまとめた、版のある束である。配られたもの、または利用者が手元の文書から作ったもの (04 §1)。
- 版ごとに中身は変わらない。更新は新しい版を入れて切り替える。
- カートリッジからメモリへは何も書き写さない。

## 2. 形式 (`.evocart`)

zip (圧縮なし) で、中身は次のとおり。

| ファイル | 中身 |
|---|---|
| `manifest.toml` | 形式の版、ID、版、題、説明、ライセンス、作成者、作成時刻、言語、チャンク分割の方式と版、同梱した埋め込みのモデル名と model_key |
| `docs/` | 正規化した本文 (UTF-8 の Markdown かテキスト) と、元のパス・見出しの道筋 |
| `chunks.jsonl` | チャンク。ID は内容から決まるハッシュ。文書、範囲、見出しの道筋、本文 |
| `embeddings/<model_key>.f16` | 任意。チャンクの埋め込み (同梱したモデルと同じなら、導入時の再計算を省ける) |
| `checksums.txt` | 全ファイルの SHA-256 |
| `checksums.txt.minisig` | `checksums.txt` の minisign の署名 (任意) |

## 3. 操作

| 操作 | 内容 | 版 |
|---|---|---|
| 導入 (`evorag cartridge add <file>`) | 署名とハッシュを確かめてから展開し、台帳に登録する。既定で有効にする | v0.5 |
| 検証 (`verify <file>`) | 導入せずに、署名・ハッシュ・パスの安全を確かめる | v0.5 |
| 作成 (`build <folder>`) | 手元の文書から作る (§4)。署名は任意 (秘密鍵はパスで受け、保存しない) | v0.5 |
| 一覧・有効化・無効化 (`list`・`enable`・`disable`) | 無効にしたものは検索しない。セッションごとに使うカートリッジを `/sources` で絞れる | v0.5 |
| 削除 (`remove`) | 展開した中身と索引を消す | v0.5 |
| 更新 | 新しい版を導入し、索引ができたら切り替える。前の版は 1 つ残し、戻せるようにする | v0.6 |

### 3.1 導入の安全

- **署名**: 信頼する鍵 (設定 `cartridge.trusted_keys`) で検証できたものは「署名あり」。署名の無いもの・利用者が手元で作ったものは「手元で作成」と記録して表示する。**署名が壊れているもの** (署名はあるが検証できない) は導入しない。
- **パスの安全** (zip slip など): `..`・絶対パス・ドライブ名・Windows の予約名 (`CON` など)・`:` (代替データストリーム)・大文字と小文字だけが違う重複・NFC と NFD だけが違う重複・シンボリックリンク・`checksums.txt` に無いファイルを含むものは拒否する。
- **大きさの上限**: ファイルの数、展開した後の合計 (既定 2 GiB)、1 ファイルの大きさ (既定 256 MiB)。
- **手順**: 一時フォルダに展開して検証してから、`cartridges/<CartridgeId>/<version>/` に rename する。展開したものは読み取り専用にする。
- 260 文字を超えるパスに備える (Windows)。

## 4. 文書の取り込み (作成のとき)

1. **文字コード**: UTF-8 にそろえる (`encoding_rs` で Shift_JIS・EUC-JP なども読む)。
2. **正規化**: NFKC、改行と空白をそろえる。HTML (v0.6) は本文と見出しだけを取り出す。
3. **分割**: 見出しの構造に沿って区切る。小さなチャンク (検索用、目安 300〜500 トークン) と、それを含む節 (添える用) の親子で持つ。表とコードブロックは途中で切らない。
4. **前置き**: チャンクの埋め込みには、文書名と見出しの道筋を前に付ける (決定論。LLM は使わない)。
5. **ID**: チャンクの ID は内容のハッシュ。同じ文書からは同じ ID になり、版を上げたときに変わった部分だけを埋め込み直せる。

## 5. 導入したあとの索引

- 同梱の埋め込みの model_key が今の embed のモデルと同じなら、それですぐに索引を作る。
- 違えば、語彙の索引だけをすぐに作り、埋め込みは sleep-time に少しずつ作る。それまでは語彙の検索だけで答え、TUI に進み具合を出す。
- 作った埋め込みは `evorag.redb` に `embedding` の記録として置き (ベクトルは `blobs`)、カートリッジ自体は書き換えない。
- 索引の置き場所は `index/cartridge/<CartridgeId>@<version>/` の下の `chunk-lex/` と `vec-<embed の model_key>/` (05 §2.3)。

## 6. 応答での扱い

- 出典 (文書名と見出し) つきで、信頼しない引用の枠に入れる (05 §4.3)。
- しきい値を超えるものが無ければ「見当たらない」ことを伝える (05 §4.4)。
- メモリと食い違うときは両方を出典つきで並べる。
